midi19 Yama-bruh drums

DRUM presets 3–10 append YB STANDARD, YB ELECTRO, YB POWER, YB BRUSH, YB ORCH, YB SYNTH, YB LATIN and YB LOFI. Their KIT values are 10–17; prior IDs are retained. Nine core sounds share the existing eight lanes: cowbell and GM cymbal notes share the BELL lane. Per-drum controls and sends still apply.

The fixed-point port follows Yama-bruh’s drum worklet at commit 3eca861, including its bank overrides. TUNE moves both oscillators and the pitch sweep; TONE changes FM index; DECY changes amplitude decay; SNAP changes the sweep, click and clap burst width. These are synthesized adaptations, with no sample-slot use. The MIT notice is included in the release license files and Lucian Labs is credited on the device.

Editor branding

The animated gold gem cursor is the local pointer from WaveLoop, by Lucian Labs. The two JavaScript source files are vendored unchanged from the live site on 2026-10-09: artifact-cursor.js (SHA-256 fb429e47064ad8384cf90147ce8c2b823ff9c4ca025fa9b43c568b07694eb5be) and ultra-cursor.js (07600fdf2a23ef2e6806f45c86714015c3bc0e47acf7a5f873d2e2c7296e2238). Only the local cursor is initialized; no presence service or remote tracking is started. All cursor assets ship with the editor.

The gem follows control type, including vertical mixer faders and sample trimming or panning. An active editor operation adds a delayed busy orb. Reduced motion uses static poses; touch and forced-colors keep native behavior. The native cursor returns when the page loses focus or the module cannot start. Cursor geometry, click animation, reduced motion, drawing bounds and busy timing are covered by six checks in web/test_cursor.mjs. Editor session tests verify busy feedback clears on completion or disconnection and ignores stale completions. Browser checks with the simulated device cover visible animation, fader dragging and native appearance selection; physical touch and forced-colors behavior are source-reviewed, not device-tested.

The editor uses WaveLoop’s navy surfaces, blue accents and gold connection control. Micro 5 is reserved for the wordmark; Finlandica handles controls and text, with Inconsolata for readouts. Dark is the default; Settings offers Light and System. That choice stays in this browser and never changes the FM-1 screen. Fonts and theme tokens are hosted with this site; no external font service is used.

The tokens are an unmodified snapshot of WaveLoop’s ds/src/tokens.css (SHA-256 7b20126cecc6175ccbfbfc3bc0db5567afc3dfa54f556ac67cbbbd70b0274e7e, 2026-10-09). Font notices: Micro 5, Finlandica, Inconsolata.

The branding and cursor changes were editor-only updates, introduced with midi19. MIDI port discovery, raw firmware identity, saved file formats and browser-library storage keys remain compatible. The product is named WaveLoop Kit; FM-1 remains the hardware name. Browser exports use WaveLoop-Kit; existing firmware download names remain valid. Legacy mixer behavior: on firmware 0.8, changing pan may briefly select that track; newer firmware can address it directly.

Validation: editor protocol and backup suites pass. Desktop and 390-pixel previews were checked with the simulated device; all ten tabs fit without page-wide overflow. Light/Dark/System selection, reload persistence, English/Japanese labels and visible keyboard focus were checked. No physical-device MIDI test was needed for this visual update.

MiniLab modifier

A-bank pad 1 sends channel 16 note 36 as a momentary modifier. Notes 37–43 remember their press layer through release; note-on velocity zero releases. Panic/reset and MIDI overflow clear modifier and held layers. Shift + note 43 taps tempo; shifted notes 37–42 and top knobs 1–4 are unassigned. Shifted faders set track delay + reverb together on fixed channels 1–4; existing per-drum send overrides remain independent.

midi17 maps shifted bottom knobs 5–8 (CC28/29/30/76) to the addressed synth track’s attack, decay, sustain and release. FM6 instead uses its existing algorithm, feedback, modulator ratio and modulator envelope time macros (P_E0/P_E1/P_E3/P_E4). Higher time values make the modulator envelopes slower. DRUM shifted knobs are unassigned. This is a mapping change using existing parameters; DSP and saved sound formats are unchanged. The controller preset is unchanged; updating the firmware enables the new layer. The editor MiniLab tab separates normal and shifted knob mappings and remains an offline reference page.

Drum kits

midi16 revoices the 808 and CR78 synthesis models introduced as DRUM presets 1 and 2 in midi14. Preset and lane IDs are unchanged. Existing songs and user sounds selecting KIT 80 or CR78 use the revised voices while retaining their saved per-drum settings. Other kit models are unchanged.

808 gains a longer bass-drum tail, stronger snare body and transient, a fuller clap tail and smoother metallic hats. CR78 uses shorter, drier kick and snare voices, broader maraca noise, woody conga, shorter claves and a rounded sine-based bell. These are original synthesized approximations, not circuit replicas or sampled instruments.

The CR78 adaptation uses maracas in lane 3, conga in lane 6, claves in lane 7 and bell in lane 8. Its longer open hat is an adaptation; this eight-lane bank does not reproduce all eleven instruments of the original machine. Per-drum editing, mixing, persistence and pattern paging retain their existing behavior.

Character references: Roland’s TR-808 overview and CR-78 overview. These describe the source instruments; they are not measurements or validation of this mod.

Developer readouts

The editor’s Dev tab polls read-only telemetry every two seconds while visible and idle. It shows linker RAM allocations, fixed audio/display buffers, firmware image headroom, encoded sample capacity, CPU load, audio overruns, MIDI/USB counters and autosave state. RAM is allocated capacity, not heap or stack usage; mapped flash span is not a chip-size measurement. Storage reservations remain fixed. Save readouts exports a local JSON snapshot; demo data is labeled.

Persistence

The 12-song setlist uses original projects A–C and nine additional A/B flash pairs in the retired third sample slot. Project 4 remains the recovery journal. Order has its own A/B pair. Commits wait for stopped transport, no held notes, five seconds of rendered silence and settled edits.

Backup includes all 12 songs, order, recovery, settings, presets and two sample slots. Older archives remain readable. Archives containing a third sample must be migrated before restoring into this mod.

Support

Check MiniLab User 5 is active if knobs or faders target the wrong controls. Download a backup before changing firmware. Report issues with the connected version and a short description of the gesture; keep private backups private.
